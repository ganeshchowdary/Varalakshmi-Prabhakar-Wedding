# Varalakshmi & Prabhakar Wedding Invitation

A responsive static wedding invitation website built with HTML, CSS, and JavaScript.

## Files
- `index.html` — content and sections
- `style.css` — visual styling and mobile layout
- `script.js` — countdown and photo lightbox

## Run on Windows
1. Extract the ZIP file.
2. Open the extracted `Varalakshmi-Prabhakar-Wedding` folder in Visual Studio Code.
3. Open `index.html` in a browser by double-clicking it in File Explorer.
4. Internet access is needed for the sample photos and Google Fonts.

You can also install the VS Code extension named **Live Server**, then right-click `index.html` and choose **Open with Live Server**.

## Customize before publishing
- Replace sample gallery image URLs in `index.html` with your own photo files.
- Update the event dates in `index.html` once Haldi and Mehendi dates are confirmed.
- Verify the Google Maps result for D.N.R Convention Hall before sharing.
- Add any family names or extra invitation wording directly in `index.html`.

## Publish with GitHub Pages
1. Create a GitHub account and a new **public** repository, for example `Varalakshmi-Prabhakar-Wedding`.
2. Upload the contents of this folder (not the outer ZIP).
3. In the repository, open **Settings → Pages**.
4. Under build/deployment, select **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. The URL appears on the Pages settings screen.

Note: GitHub Pages sites are public. Only publish photos and details you are comfortable making public.
